Google Sheet Integration

To link your sheet (1fHhTtag...eG4s), deploy a Google Apps Script Web App and paste its script.google.com URL below.

Please enter the Apps Script Web App URL (starts with script.google.com), not the spreadsheet edit link. See guide below.

Setup Guide & Script Code

1. Open your Google Sheet, click Extensions > Apps Script.

2. Delete any existing code and paste this snippet:

function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  sheet.appendRow([
    data.timestamp,
    data.date,
    data.studentName,
    data.studentGroup,
    data.score,
    data.totalQuestions,
    data.percentage + '%',
    data.attainmentLevel,
    data.certId,
    data.domain1,
    data.domain2,
    data.domain3,
    data.domain4,
    data.domain5
  ]);
  return ContentService.createTextOutput("Success");
}

3. Click Deploy > New deployment.

4. Select Web App, set Who has access to "Anyone", click Deploy.

5. Copy the Web App URL and paste it into the field above.
